# EduVibe - Tutor & Student Platform

EduVibe is a comprehensive Android application designed to bridge the gap between teachers and students. It provides a robust platform for teachers to manage their profiles, classes, and students, while offering students a seamless experience to find mentors and track their educational goals.

## 🚀 Features

### For Teachers
*   **Onboarding & Profile Creation:** Multi-step profile setup to showcase expertise.
*   **Dashboard:** Centralized hub to manage daily activities, sessions, and students.
*   **Class Management:** Create and organize classes and courses.
*   **Student Tracking:** Keep track of enrolled students and their progress.
*   **Communication:** Integrated chat system for real-time interaction with students.
*   **Payments & Earnings:** Manage payment methods and track rankings.
*   **Settings & Personalization:** Detailed personal info management and account controls.

### For Students
*   **Mentor Discovery:** Browse and connect with expert mentors.
*   **Goal Tracking:** Set and monitor class goals.
*   **Live Support:** Access to support and live chat features.
*   **Notifications:** Stay updated with class schedules and announcements.

## 🛠 Tech Stack

*   **Language:** [Kotlin](https://kotlinlang.org/)
*   **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
*   **Design System:** Material 3
*   **Navigation:** Jetpack Navigation Compose
*   **Image Loading:** [Coil](https://coil-kt.github.io/coil/)
*   **Local Storage:** SharedPreferences for session management.
*   **Architecture:** Modern Android Architecture (MVVM patterns implied).

## 🏗 Project Structure

The project is organized into modular packages:
*   `com.example.tutorapp`: Main entry point and student-side screens.
*   `com.example.tutorapp.teacher`: Dedicated package for teacher-specific screens and navigation logic.
*   `com.example.tutorapp.ui.theme`: Theming and styling constants.
